**KEGG通路背景概况：**22个通路按大类分布为：Metabolism（代谢，13个通路，329个代谢物）、Organismal Systems（有机体系统，5个通路）、Human Diseases（人类疾病，2个通路）、Environmental Information Processing（环境信息处理，2个通路）、Cellular Processes（细胞过程，1个通路）和Genetic Information Processing（遗传信息处理，1个通路）。最大通路为"次级代谢物生物合成"（87个代谢物），其次为"脂质代谢"（73个）和"氨基酸代谢"（56个）。

###二、KEGG通路富集分析结果三组比较的Fisher精确检验显示，在严格的FDR <0.05阈值下，虽然没有任何通路达到统计学显著性，但多个通路在原始p值水平呈现较强的富集趋势：

**FE_vs_CD（核心比对）**中，最接近显著的通路包括"次级代谢物生物合成"（36/87差异代谢物，p=0.037）和"细胞生长与死亡"（4/5，p=0.041），表明高铁饮食干预对CDI感染背景下的菌群次级代谢和宿主细胞过程产生了明显影响。"脂质代谢"通路含有27/73个差异代谢物，与知识库中高铁饮食减少产SCFA有益菌群的机制预期一致。

**CD_vs_NC（模型验证）**中，最突出的通路为"蛋白质折叠、分选与降解"（3/4，p=0.042）和"内分泌系统"（4/8，p=0.092），反映了CDI感染本身引起的宿主应激反应和内分泌调节变化。

**FE_vs_NC（整体效应）**中，"细胞生长与死亡"（3/5，p=0.168）和"脂质代谢"（26/73，p=0.180）为富集最明显的通路。

**富集分析未达显著的原因：**主要由于KEGG的代谢物注释覆盖度有限（仅21.7%的代谢物有通路映射），加之Fisher精确检验在小样本通路中较为保守，多重检验校正后均未达到FDR阈值。

###三、GSVA分析结果GSVA作为不依赖于差异代谢物计数的非参数打分方法，弥补了富集分析的局限性，揭示了更深层的通路活性变化。

**GSVA差异分析（LIMMA）显著结果：**

|比对组 |显著通路 |上调 |下调 |
|:---|:---:|:---:|:---:|
| **FE_vs_CD** | **13/22** |6 |7 |
| **CD_vs_NC** | **3/22** |3 |0 |
| **FE_vs_NC** | **9/22** |4 |5 |

**FE_vs_CD（核心比对）关键发现：**

- **信号转导通路大幅下调**（logFC = -0.96，p_adj =3.4×10⁻⁶）：这是所有通路中变化幅度最大、显著性最强的通路，提示高铁饮食在CDI感染背景下可能抑制了宿主的免疫信号传递通路。该发现与知识库中"高铁饮食改变宿主肠道中性粒细胞招募"的机制直接呼应，信号转导通路的抑制可能削弱了宿主对艰难梭菌的免疫应答能力。

- **能量代谢通路显著上调**（logFC = +0.90，p_adj =8.6×10⁻⁵）：反映高铁饮食对肠道细胞能量代谢的促进作用，可能通过增强铁依赖的线粒体呼吸链活性来实现。

- **排泄系统通路上调**（logFC = +0.73，p_adj =2.3×10⁻⁵）：可能与高铁负荷下宿主增强的金属离子排泄和解毒机制有关。

- **神经系统通路下调**（logFC = -0.77，p_adj =3.5×10⁻⁵）：反映"肠-脑轴"在高铁饮食与CDI双重影响下的功能扰动。

- **次级代谢物生物合成上调**（logFC = +0.31，p_adj =1.9×10⁻³）：与富集分析趋势一致，提示高铁饮食促进了肠道菌群的次级代谢活动，这与知识库中高铁饮食增加肠杆菌科的预期相符。

- **脂质代谢下调**（logFC = -0.22，p_adj =0.039）：直接验证了知识库中"高铁饮食减少SCFA产生有益菌"的预期，脂质代谢通路活性降低可能反映了产SCFA菌群丰度的下降。

- **糖代谢通路上调**（logFC = +0.35，p_adj =6.0×10⁻³）：可能反映艰难梭菌在高铁环境下增强的糖酵解代谢活动。

**CD_vs_NC（模型验证）：**3个通路显著且全部上调——"癌症总览"（+0.71）、"糖缀合物生物合成"（+0.56）、"感觉系统"（+0.61），验证了CDI感染本身触发的宿主防御和应激信号。

**FE_vs_NC（整体效应）：**9个通路显著，变化模式与FE_vs_CD高度一致（信号转导↓、排泄系统↑、能量代谢↑、神经系统↓、脂质代谢↓），表明高铁饮食在感染和非感染状态下均可产生类似的通路活性调控。

###四、通路得分热图的样本聚类模式GSVA热图按KEGG大类分组后呈现清晰的聚类结构：样本按NC → CD → FE分组顺序自然分离，组内一致性良好，组间差异显著。NC组样本在"脂质代谢"和"辅助因子和维生素代谢"通路中聚集高活性，而FE组在"能量代谢"和"排泄系统"通路中特异性高活性。CD组则呈现中间状态。各KEGG大类内的通路层次聚类树显示了通路间的协同调控关系，例如代谢类通路中"脂质代谢"与"能量代谢"聚为功能相关的亚簇。
