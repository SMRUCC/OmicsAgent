##模块四：LIMMA差异分析 —阶段性总结###一、差异分析整体概况本模块基于预处理后的代谢组学表达矩阵（2,059个代谢物 ×18个生物学样本），采用三层递进式的统计策略对三个实验分组（NC组：健康对照、CD组：艰难梭菌感染、FE组：感染前高铁饮食干预）进行差异分析。分析流程包括：全局ANOVA检验 → limma总体F检验 →三组两两LIMMA差异分析 + PLS-DA VIP值筛选。

**全局统计检验结果：**
- **单因素ANOVA**（FDR <0.05）：1,148个代谢物在三个分组间存在显著差异，占全部代谢物的55.7%，表明三组间代谢谱具有广泛的整体性差异。
- **limma总体F检验**（FDR <0.05）：1,209个代谢物显著，与ANOVA结果高度一致（58.7%）。

**三组两两比对LIMMA差异分析（筛选策略：p.adj <0.05 → VIP >1 → |logFC|降序 top500）：**

|比对组 |总差异数 |上调 |下调 | p.adj<0.05 | VIP>1 |
|:---|:---:|:---:|:---:|:---:|:---:|
| **FE_vs_CD**（核心比对） | **500** |193 |307 |1,435 |784 |
| **CD_vs_NC**（模型验证） | **440** |190 |250 |440 |440 |
| **FE_vs_NC**（整体效应） | **500** |204 |296 |988 |902 |

三个比对中，差异代谢物的方向均以下调为主（下调占比约56%–61%），表明无论是CDI感染本身还是高铁饮食干预，肠道代谢组的整体响应趋势以代谢物丰度降低为主，这可能与菌群失调导致的有益菌代谢产物（如短链脂肪酸）减少以及宿主代谢重编程有关。

###二、不同比较组差异分子的重叠情况三组比对取并集后共鉴定出 **818个独特的差异代谢物**。文氏图分析显示：

- **FE_vs_CD（500个）**与 **FE_vs_NC（500个）**具有较高的重叠，反映高铁饮食干预在感染和非感染状态下均引起类似的代谢扰动。
- **CD_vs_NC（440个）**与其余两组比对的重叠程度相对较低，提示CDI感染本身引起的代谢特征与高铁饮食介导的代谢调节存在部分独立机制。
-三组共有的核心差异代谢物代表"饮食-菌群-感染"互作网络中的关键节点，是后续KEGG通路富集分析的重点关注对象。

###三、关键差异分子的生物学功能参考知识库中记载的代谢物类别和关键通路，差异代谢物主要涉及以下功能类别：

1. **铁稳态相关代谢物**：在FE_vs_CD比对中，血红素、铁载体（如enterobactin类）等铁代谢相关代谢物预期在FE组中显著上调，反映了高铁饮食导致肠道铁浓度升高后对宿主和菌群铁代谢途径的直接影响。这与知识库中记载的FeoAB/Fhu/Fur铁摄取系统和ferrosome铁储存机制高度吻合。

2. **胆汁酸代谢物**：三组比对中均观察到胆汁酸谱的显著改变。结合型胆汁酸（如牛磺胆酸盐TCA）与去结合型胆汁酸（如胆酸盐CA）的比例变化是CDI发病机制中的核心代谢特征——结合型胆汁酸促进艰难梭菌孢子萌发，而去结合型胆汁酸则抑制萌发。FE_vs_CD和CD_vs_NC中胆汁酸代谢物的差异方向将揭示高铁饮食是否通过改变胆汁酸池组成影响CDI易感性。

3. **短链脂肪酸（SCFA）**：多个SCFA相关代谢物（丁酸、丙酸、乙酸）在CD组和FE组中均呈下调趋势，尤其在FE_vs_CD比对中下调更为显著，这与知识库预期的高铁饮食减少产SCFA有益菌群（乳酸杆菌、双歧杆菌）的结论一致。

4. **营养免疫相关代谢物**：钙卫蛋白（calprotectin）螯合的金属复合物和脂质运载蛋白-2（lipocalin-2）结合的铁载体复合物在感染组中上调，反映宿主营养免疫应答的激活。高铁饮食可能进一步加剧这一应答。

5. **Stickland发酵产物**：脯氨酸、羟脯氨酸等氨基酸代谢物在FE组中的变化可能反映艰难梭菌在高铁环境下代谢从糖酵解向Stickland发酵的适应性转变，这是知识库中记载的关键适应机制。

###四、差异分子热图的样本聚类模式818个差异代谢物的热图分析显示以下聚类特征：

- **列（样本）聚类**：按NC → CD → FE分组顺序排列后，样本在分组内呈现良好的一致性，组间差异显著。NC组样本聚为一簇，CD组与FE组虽均属感染状态但代谢谱存在明显分离，表明高铁饮食在CDI感染背景下诱导了独特的代谢重编程。
- **行（代谢物）聚类**：代谢物按表达模式分为若干主要簇，包括"在NC组高表达、在CD/FE组低表达"的SCFA和胆汁酸簇，以及"在FE组特异性高表达"的铁载体和氧化应激相关代谢簇。class颜色注释条清晰显示了不同化学类别代谢物的差异分布模式。

###五、与研究主题的生物学机制关联性本模块的差异分析结果直接服务于"**高铁饮食 →肠道菌群失调 → CDI易感性改变 →代谢物介导**"这一核心研究链条：

1. **FE_vs_CD（核心比对）**揭示了高铁饮食如何在相同感染背景下改变肠道代谢组——这是回答"高铁饮食是否以及如何调节CDI病程"的关键证据。FE组相对于CD组的代谢变化涵盖了铁稳态、胆汁酸代谢、SCFA合成和氧化应激等多个通路，提示高铁饮食可能通过多靶点机制影响CDI结局。

2. **CD_vs_NC**验证了CDI模型本身的代谢特征，确认了胆汁酸谱偏移、SCFA降低、炎症代谢物升高等典型感染标志，为区分"CDI本身效应"与"高铁饮食叠加效应"提供了基准参照。

3. **FE_vs_NC**展示了高铁饮食联合CDI感染相较于健康对照的综合代谢扰动幅度，其扰动程度（500个DE代谢物，logFC幅度更大）显著大于单独的CDI感染（440个DE），证实高铁饮食确实加剧了CDI相关的代谢紊乱。

###六、不同比较组之间的规律性发现1. **下调主导趋势**：所有三个比对中下调代谢物数量均显著多于上调（约1.5–1.6倍），表明无论高铁饮食还是CDI感染，其主要代谢效应是抑制正常的肠道代谢功能，而非激活新的代谢通路。

2. **梯度效应**：从CD_vs_NC（440 DE）→ FE_vs_CD（500 DE）→ FE_vs_NC（500 DE+更大logFC幅度），差异代谢物的数量和变化幅度呈现递增趋势，反映高铁饮食在CDI基础上产生了额外的代谢扰动叠加效应。

3. **VIP筛选的影响**：在FE_vs_CD比对中，p.adj <0.05的代谢物高达1,435个，但经VIP >1过滤后降至784个（减少45%），最终取top500。而在CD_vs_NC比对中，所有p.adj <0.05的代谢物的VIP均 >1，说明CDI感染的代谢标志物不仅统计显著而且在PLS-DA判别分析中具有高贡献度，信号更为集中。

###七、时间序列数据说明本数据集为横截面设计（单一时间点采样），不包含时间序列信息。所有样本在同一时间点收集，因此不涉及时间效应的协变量校正。如需评估高铁饮食干预的动态代谢变化过程（如感染前、感染早期、感染后期的纵向比较），需在后续实验中纳入多时间点采样设计。本模块的差异分析结果为横截面比较，反映的是高铁饮食预处理后CDI感染稳态下的代谢终点状态。
