👋 欢迎使用科研数据分析智能工作站

本工作站是一套以本地 Ollama 大语言模型（LLM）智能体为核心的科研数据分析平台。智能体能够依据您的研究主题自动设计分析方案，并自主编写模块化 R 脚本， 完成从表达矩阵预处理、总体分析、差异分析、功能富集、共表达网络、聚类、因果路径、机器学习预测到跨组学整合的全流程组学生物信息学分析， 最终自动整理结果表格并撰写论文初稿报告（PDF / DOCX）。配合文献知识库（RAG 检索与图谱化）、数据集定义编辑器、结果浏览器、Venn 图与文件查看器等图形化辅助模块， 为科研人员提供从文献调研、方案设计、数据剖析到结果输出的端到端一体化工作环境。

🤖 智能体分析流水线

LLM Agent 自主编排 · 模块化 R 脚本实现

01 表达矩阵预处理

缺失值填充、归一化、log 变换与中位数缩放，构建标准分析输入。

02 总体分析

PCA / PLSDA / OPLSDA 降维可视化，F 检验 / ANOVA 初筛与样本重复性 QC。

03 差异组别设计

由 LLM 依据研究假设智能设计差异分析比对组别与对照方案。

04 LIMMA 差异分析

基于 LIMMA 的差异表达鉴定，输出火山图、文氏图与差异热图。

05 KEGG 功能分析

差异基因 KEGG 富集分析与 GSVA 通路评分，条形图 / 热图 / 火山图呈现。

06 WGCNA 共表达网络

构建共表达模块，关联生物学性状并进行 KEGG 富集解读。

07 CMeans 模糊聚类

模糊 C 均值聚类识别样本亚型，结合 WGCNA 与 KEGG 进行功能注释。

08 动态贝叶斯网络

基于 bnlearn 推断变量间调控与因果关系网络。

09 PLS-PM 因果路径

偏最小二乘路径建模，解析多组学层次潜变量间的因果路径。

10 随机森林预测

RFE 特征选择、AUC 评估与特征重要性排序，挖掘生物标志物。

11 回归分析

逻辑 / 线性回归建模，导出回归方程并辅以 VIF / LASSO 诊断。

12 跨组学整合分析

多组学（转录 / 蛋白 / 代谢 / 脂质）样本对齐后的整合建模（多组学专用）。

13 结果表格整理

汇总关键结果至 xlsx，套用 Cambria Math 样式与冻结窗格便于审阅。

14 论文初稿撰写

自动生成 PDF / DOCX 报告，中英图注齐全，可直接用于论文初稿。
